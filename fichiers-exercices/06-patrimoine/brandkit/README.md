# Kit de marque — Cabinet Altius Patrimoine

Cabinet Altius Patrimoine — gestion de patrimoine (CGP).

## Contenu du dossier
- `brandkit.md` — la charte de marque (couleurs, typographies, ton de voix, concept de logo)
- `logo.svg` / `logo.png` — le logo
- `sample-post.svg` / `sample-post.png` — un exemple de visuel marketing

## Générer un visuel dans Canva (connecteur)
Ouvrez Claude avec le connecteur Canva et collez ce prompt :

> Crée un invitation atelier pour **Cabinet Altius Patrimoine**, gestion de patrimoine (CGP). Couleurs de marque : #1A2A4F / #B8943F / #C9CDD4. Police des titres : Cormorant Garamond. Ton : posé et haut de gamme. Message principal : « Préparez votre retraite sereinement ». Bouton d'appel à l'action : « Prenons rendez-vous ». Place le nom de la marque en bas du visuel.

## Pour aller plus loin
Changez le message, les dates ou l'offre, puis relancez : observez Canva adapter le visuel à la marque. Demandez aussi une **déclinaison** (story, flyer, bannière) à partir du même message.
