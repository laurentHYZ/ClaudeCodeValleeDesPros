# Kit de marque — Domaine Les Restanques & La Lézardière

Domaine Les Restanques & La Lézardière — camping, chambres d'hôtes et cave dans le Luberon.

## Contenu du dossier
- `brandkit.md` — la charte de marque (couleurs, typographies, ton de voix, concept de logo)
- `logo.svg` / `logo.png` — le logo
- `sample-post.svg` / `sample-post.png` — un exemple de visuel marketing

## Générer un visuel dans Canva (connecteur)
Ouvrez Claude avec le connecteur Canva et collez ce prompt :

> Crée un story Instagram pour **Domaine Les Restanques & La Lézardière**, camping, chambres d'hôtes et cave dans le Luberon. Couleurs de marque : #C0613B / #6E7B4D / #E3A857. Police des titres : Playfair Display. Ton : chaleureux et sensoriel. Message principal : « Le Luberon, en toute saison ». Bouton d'appel à l'action : « Réservez votre séjour ». Place le nom de la marque en bas du visuel.

## Pour aller plus loin
Changez le message, les dates ou l'offre, puis relancez : observez Canva adapter le visuel à la marque. Demandez aussi une **déclinaison** (story, flyer, bannière) à partir du même message.
